# Windows 运行步骤

建议本地目录：

```text
E:\My GitHub\pcb-defect-vision-analysis
```

## 1. 创建 Python 虚拟环境

```powershell
cd "E:\My GitHub\pcb-defect-vision-analysis"

py -m venv .venv
.\.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
pip install -r requirements.txt
```

## 2. 下载 DeepPCB

在项目目录执行：

```powershell
git clone https://github.com/tangsanli5201/DeepPCB.git "data\raw\DeepPCB"
```

确认目录存在：

```text
data\raw\DeepPCB\PCBData
```

## 3. 数据审计

```powershell
python src\00_audit_raw_dataset.py
```

主要输出：
- `outputs/raw_dataset_inventory.csv`
- `outputs/raw_dataset_issues.csv`
- `outputs/raw_class_counts.csv`

## 4. 转换为 YOLO 数据结构

```powershell
python src\01_prepare_yolo_dataset.py
```

主要输出：
- `data/prepared/dataset.yaml`
- `data/prepared/split_manifest.csv`
- train / val / test 图像与标注

## 5. OpenCV 基线

```powershell
python src\02_opencv_baseline.py
```

输出：
- `baseline_metrics.csv`
- image-level结果
- 前20张差分、mask和框可视化

## 6. 训练 YOLOv8n

```powershell
python src\03_train_yolo.py
```

默认：
- 60 epochs
- 640×640
- YOLOv8n
- 自动选择 GPU / CPU

首次运行时 Ultralytics 可能需要下载 `yolov8n.pt`。

## 7. 模型评估与阈值扫描

```powershell
python src\04_evaluate_yolo.py
```

输出：
- Precision / Recall
- mAP@0.5
- mAP@0.5:0.95
- threshold scan
- Best-F1工作点
- 高召回工作点
- 类别级 Precision / Recall / F1
- FP / FN案例清单

## 8. 质量分析

```powershell
python src\05_quality_analysis.py
```

输出：
- 类别Recall图
- 阈值—Precision/Recall/F1曲线
- 错误类别Pareto
- Top 20错误样本清单

## 9. 分阶段流水线

先验证数据与传统视觉：

```powershell
python src\run_pipeline.py --steps audit prepare opencv
```

GPU环境确认后再运行：

```powershell
python src\run_pipeline.py --steps train evaluate quality
```

不建议第一次直接一键全跑，便于逐阶段检查结果。
