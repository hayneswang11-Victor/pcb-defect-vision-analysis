# 数据说明

本项目使用官方 DeepPCB 数据集。

官方数据包含 1,500 对已配准 PCB 图像，每对包括：
- 缺陷测试图：`*_test.jpg`
- 无缺陷模板图：`*_temp.jpg`
- 边界框标注：`.txt`

官方标注格式：

```text
x1,y1,x2,y2,type
```

类别映射：
1. open
2. short
3. mousebite
4. spur
5. copper / spurious copper
6. pin-hole

本项目会自动将类别 ID 1–6 转换为 YOLO 的 0–5。

## 数据边界

DeepPCB 官方说明数据仅供研究使用。因此本项目代码包不重新分发原始数据，用户需要自行从官方仓库获取。
